How Shiprocket works here:
1. Save your credentials above.
2. When an order is placed, it will appear in "Pending Shipments".
3. Click "Create Shipment" to auto-push the order to Shiprocket.
4. Shiprocket will generate an AWB and assign a courier automatically.
5. Tracking details will be sent to the customer's phone via WhatsApp.

Full API integration requires a backend server. For now, this panel prepares the order payload in the correct Shiprocket V2 format.
